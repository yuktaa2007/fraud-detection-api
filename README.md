# Credit Card Fraud Detection API

AI-based Credit Card Fraud Detection System using Machine Learning and Flask.

## Features
- Fraud transaction prediction
- Machine Learning model deployment
- Flask API
- Render cloud deployment

## Tech Stack
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- Render
